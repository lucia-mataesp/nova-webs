# nova-webs

Webs y plantillas de Nova publicadas con GitHub Pages. Una carpeta por web.

- `visuals/` — recursos visuales comunes (logos, fondos, iconos)
- `certificados/` — plantillas de certificados (CEU Investment Banking Program, Bright Future Program…)
- `development-programs/` — webs de los Development Programs

**Repo público:** nunca subir datos personales (nombres, emails, listas). Las plantillas reciben los datos por la URL.
